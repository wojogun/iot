# Anforderungen an die Seminararbeit
Entwickeln Sie als Gruppe auf Basis des Model-Hauses (Smart Home) Ihren eigenen Use Case und demonstrieren Sie dessen Funktionsweise.

Dabei soll jede*r Student*in einen eigenen **"Einzel-Use Case"** entwickeln und implementieren.

Zum Schluss soll ein **"Gesamt-Use Case"** entwickelt werden, bei dem alle 3 Einzel-Use Cases zusammenspielen.

Als Hilfestellung könnte der Einzel-Use Case etwas abbilden, dass nur ein einzelnes Haus betrifft. Der Gesamt-Use Case jedoch betrifft mehrere Häuser gleichzeitig (quasi wie eine Siedlung).

Wählen Sie ein **IoT-Framework** aus und setzen Sie dieses bei der Umsetzung ein. Beschreiben Sie auch in der Seminararbeit, warum Sie dieses IoT-Framework gewählt haben (Mehrwert bzw. Vorteile gegenüber anderen IoT-Frameworks) und erklären Sie, ob bzw. wie dieses IoT-Framework in der Cloud funktionieren kann (ist es Cloud-fähig).

- Info: viele Kunden fragen zum Schluss, ob man die angebotene Lösung auch lokal bzw. OnPremise installieren kann (liefern Sie dazu hier eine Antwort in Ihrer Seminararbeit).
- Ein NEIN ist hier auch OK!

Dokumentieren Sie die 3 Einzel-Use Cases und den Gesamt-Use Case und deren technische Umsetzung in Form einer Seminararbeit.

Benutzen Sie dabei die "4+1 Architectural View Model"-Methode, um ihre Umsetzung zu beschreiben. Hier Finden Sie weitere Informationen zu dieser Methode:

- Wikipedia-Beitrag: https://en.wikipedia.org/wiki/4%2B1_architectural_view_model
- IEEE Paper: https://www.cs.ubc.ca/~gregor/teaching/papers/4+1view-architecture.pdf
In der Seminararbeit müssen Sie folgende Kapitel-Überschriften haben bzw. Inhalte dazu liefern:

## Aufbau
### 1 Einleitung / Introduction
- genau eine A4-Seite!
- Leiten Sie ihre Arbeit ein und beschreiben Sie die Problemstellung bzw. den Mehrwert Ihrer Einzel- und Gesamt-Use Case Lösungen
- Beschreiben Sie die Zielgruppe Ihrer Lösung (wo wäre die Lösung am besten zu platzieren)
### 2 Use Case Sicht / Use Case View
- Beschreiben Sie jeweils jeden Einzel-Use Case
- Beschreiben Sie den Gesamt-Use Case, bei dem Sie alle Einzel-Use Cases zusammenführen
- mögliche visuelle Darstellungsformen: Anwendungsfalldiagramm
### 3 Logische Sicht / Logical View
- Beschreiben Sie die Funktionalität des Smart Home Systems für den Endnutzer
- mögliche visuelle Darstellungsformen: Klassendiagramm, Zustandsdiagramm
### 4 Entwicklungs Sicht / Development View
- Beschreiben Sie das Smart Home System vom Standpunkt einer/eines Entwicklerin/Entwicklers und dabei auf das Softwaremanagement eingehen
- mögliche visuelle Darstellungsformen: Komponentendiagramm, Paketdiagramm
- ACHTUNG: Sie sollen NICHT Source Code herzeigen, sondern dessen Funktionsweise beschreiben
- Sie dürfen gerne ein GitHub-Repo, welches den gesamten Source Code beinhaltet, als Quelle zitieren nach APA-7 (als Website)
### 5 Prozess Sicht / Process View
- Beschreiben Sie die Prozesse des Smart Home Systems und wie die einzelnen Komponenten miteinander kommunizieren (Laufzeitverhalten: WAS passiert WANN)
- Wie oft werden die Daten übertragen (Rythmik und Datenmenge). Dort wo es genau geht, geben Sie genaue Werte an (Rythmik). Dort wo man es nicht genau weiß, geben Sie ihre Einschätzung ab (z.B.: Datenmenge).
- mögliche visuelle Darstellungsformen: Sequenzdiagramm, Aktivitätsdiagramm
### 6 Physische Sicht / Physical View
- Beschreiben Sie das Smart Home System aus Sicht eines Systemarchitekten.
- Stellen Sie dabei ein Mapping zwischen den Hardware-Komponenten her, die für Ihren Use Case verwendet werden
- Welche Übertragungstechnik bzw. Sensorik wird verwendet
mögliche visuelle Darstellungsformen: Verteilungsdiagramm
### 7 Schlussfolgerungen / Conclusion
- **genau eine A4-Seite**
- Erinnern Sie den Leser/die Leserin welche Problemstellung Sie bearbeiten haben.
- Erinnern Sie den Leser/die Leserin welchen Mehrwert Ihre Smart Home Umsetzung bietet.
- Geben Sie dem Leser/der Leserin die wichtigsten "Key Take-Aways" mit, an die er/sie sich ein Leben lang erinnern soll.
- Geben Sie an, was diese Lösung kosten würde, als Fazit.


Die Seminararbeit soll 12-15 Seiten (nicht mehr und nicht weniger) haben.

**Stichwort: Quellen**

- Wenn Sie Informationen von anderen Quellen her haben, dann müssen Sie diese nach APA-7 Richtlinien angeben.
- Die Quellen müssen dabei NICHT ausschließlich wissenschaftlicher Natur sein (jede Quelle ist erlaubt, mit folgenden Ausnahmen: Wikipedia, Social Media, KI/AI)
